# 用户曲库页

## 模块 A：页面元数据

- **页面名称**：用户曲库页
- **访问路由**：`/library`
- **权限要求**：所有已登录用户可访问；忽略能力只操作当前用户自己的“我的忽略”。

## 模块 B：UI/布局结构

- **页面布局模式**：列表页，沿用统计卡片 + 搜索排序区 + 曲目表格。
- **核心区块划分**：
  - [统计卡片区]：展示已过滤后的曲目、专辑、艺人数量。
  - [搜索排序区]：按关键字和排序方式浏览默认可见曲目。
  - [曲目表格区]：在播放、标题、艺人、专辑、路径之外，新增“忽略”快捷操作。
- **页面内从属交互**：
  - [我的忽略快捷操作]：行内按钮；不走弹窗，点击后直接写入“我的忽略”。

## 模块 C：数据展示与字段定义

### 字段分组 1：搜索与筛选字段
| 字段名称 (中/英) | 数据类型 | 必填/选填 | 业务规则/约束 | 默认值 |
| --- | --- | --- | --- | --- |
| 关键字 `q` | string | 选填 | 匹配标题、艺人、专辑、文件名、路径 | 空 |
| 排序 `order` | enum | 必填 | `recent / title / artist` | `recent` |
| 可见面 `surface` | enum | 必填 | 固定传 `user`，默认过滤 `global + mine` | `user` |

### 字段分组 2：曲目表格列
| 字段名称 (中/英) | 数据类型 | 必填/选填 | 业务规则/约束 | 默认值 |
| --- | --- | --- | --- | --- |
| 播放按钮 `play` | action | 必显 | 进入全局播放器 | 无 |
| 标题 `title` | string | 必显 | 优先显示最新编辑值 | 无 |
| 艺人 `artist` | string | 选显 | 无值时显示占位 | 空 |
| 专辑 `album` | string | 选显 | 无值时显示占位 | 空 |
| 路径 `path` | string | 必显 | 只读展示 | 无 |
| 更新时间 `updatedAt` | datetime | 必显 | 表格展示 | 无 |
| 忽略按钮 `ignoreMine` | action | 必显 | 点击后把当前曲目加入“我的忽略” | 无 |

## 模块 D：交互与状态流转

### 操作 1：浏览默认曲库
- **触发事件**：进入页面、搜索、切换排序。
- **前置校验**：用户已登录。
- **流转结果**：调用 `tracks.list(surface=user)` 与 `library.stats(surface=user)`。
- **成功结果**：只返回未命中 `global` 和当前用户 `mine` 的曲目。
- **失败结果**：显示列表加载失败提示。

### 操作 2：加入我的忽略
- **触发事件**：点击行内“忽略”按钮。
- **前置校验**：曲目存在，用户已登录。
- **流转结果**：调用 `ignoredTracks.ignoreMine`，随后刷新曲库、统计与忽略列表。
- **成功结果**：写入 `user_ignored_tracks`，当前曲目从列表和统计中移除。
- **失败结果**：显示“加入我的忽略失败”提示。

### 操作 3：点播曲目
- **触发事件**：点击播放按钮。
- **前置校验**：曲目存在，用户已登录。
- **流转结果**：触发 `playback.resolve`，必要时轮询准备状态。
- **成功结果**：进入全局播放器。
- **失败结果**：展示播放失败或转码失败提示。

### 页面状态与异常
- **加载中**：统计卡片与表格显示 loading。
- **无数据**：显示空状态，不暴露“查看已忽略”切换器。
- **网络错误**：显示错误提示，允许重试。
- **无权限**：未登录时跳转 `/sign-in`。
- **重复提交**：忽略按钮在提交中显示 disabled。
- **分页逻辑**：v1 仅固定结果数量，不做完整分页。
- **搜索逻辑**：优先走 FTS，失败时降级 LIKE，并始终保留忽略过滤。
- **排序逻辑**：支持 `recent / title / artist`。
