# 登录与初始化页

## 模块 A：页面元数据
- **页面名称**：登录与初始化页
- **访问路由**：`/sign-in`
- **权限要求**：未登录可访问；已登录访问由 proxy 跳转 `/dashboard`。

## 模块 B：UI/布局结构
- **页面布局模式**：居中单卡片。
- **核心区块划分**：
  - 初始化表单：系统无管理员时显示。
  - 登录表单：系统已有管理员时显示。
- **页面内从属交互**：无单独弹窗或抽屉。

## 模块 C：数据展示与字段定义
### 初始化字段
| 字段名称 | 数据类型 | 必填/选填 | 业务规则/约束 | 默认值 |
| --- | --- | --- | --- | --- |
| 昵称 name | string | 选填 | 为空时后端使用 Admin | 空 |
| 邮箱 email | string | 必填 | 合法邮箱 | 无 |
| 密码 password | string | 必填 | 至少 8 位 | 无 |

### 登录字段
| 字段名称 | 数据类型 | 必填/选填 | 业务规则/约束 | 默认值 |
| --- | --- | --- | --- | --- |
| 邮箱 email | string | 必填 | 可由 `email` query 预填 | 空 |
| 密码 password | string | 必填 | 交给 better-auth 校验 | 空 |

## 模块 D：交互与状态流转
### 创建首个管理员
- **触发方式**：提交初始化表单。
- **前置校验**：邮箱非空且格式合法；密码至少 8 位；系统未初始化。
- **成功结果**：创建 `admin` 用户，回到登录表单并预填邮箱。
- **失败结果**：显示错误提示，不进入业务页面。

### 登录
- **触发方式**：提交登录表单。
- **前置校验**：邮箱和密码必填。
- **成功结果**：跳转到安全的内部 `next`，没有 `next` 时进入 `/dashboard`。
- **失败结果**：显示登录失败提示。

### 页面状态与异常
- **加载中**：服务端读取初始化状态，客户端不展示独立 loading 页。
- **无权限**：已登录访问 `/sign-in` 时直接跳转 `/dashboard`。
- **重复提交**：提交中禁用按钮。
- **旧入口**：`/setup` 不再提供页面，作为 unsafe callback 回退到 `/dashboard`。

## 模块 E：复杂业务逻辑图
无额外复杂状态流转。
