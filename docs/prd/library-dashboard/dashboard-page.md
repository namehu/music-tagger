# 用户首页

## 模块 A：页面元数据

- **页面名称**：用户首页
- **访问路由**：`/dashboard`
- **权限要求**：所有已登录用户可访问；管理员在用户区内也复用该页。

## 模块 B：UI/布局结构

- **页面布局模式**：顶部说明 + 统计卡片 + 继续收听主卡 + 最近播放 + 最近更新的歌单 + 最近更新的曲目 + 快捷入口。
- **核心区块划分**：
  - [统计卡片区]：展示用户当前可见的曲目、专辑、艺人数。
  - [继续收听区]：复用当前播放摘要，作为首页主卡。
  - [最近播放区]：展示最近点播过的曲目，并提供继续播放按钮。
  - [最近更新的歌单区]：展示当前用户最近维护过的歌单。
  - [最近更新的曲目区]：展示当前用户仍可见的最近更新曲目。
  - [快捷入口区]：提供去音乐库、歌单、我的忽略的快捷入口。
- **页面内从属交互**：
  - [继续播放]：来自最近播放区，直接接入全局播放器。
  - [打开歌单]：跳转歌单详情页。
  - [前往音乐库]：跳转完整曲库页。

## 模块 C：数据展示与字段定义

### 字段分组 1：首页聚合数据
| 字段名称 (中/英) | 数据类型 | 必填/选填 | 业务规则/约束 | 默认值 |
| --- | --- | --- | --- | --- |
| `stats.tracks` | integer | 必显 | 当前用户可见曲目数 | `0` |
| `stats.albums` | integer | 必显 | 当前用户可见专辑数 | `0` |
| `stats.artists` | integer | 必显 | 当前用户可见艺人数 | `0` |
| `recentPlays` | array<object> | 必显 | 基于最近点播事件去重，最多 6 首 | 空数组 |
| `recentPlaylists` | array<object> | 必显 | 按 `updatedAt desc`，最多 5 个 | 空数组 |
| `recentTracks` | array<object> | 必显 | 按 `updatedAt desc`，最多 6 首 | 空数组 |

### 字段分组 2：最近播放字段
| 字段名称 (中/英) | 数据类型 | 必填/选填 | 业务规则/约束 | 默认值 |
| --- | --- | --- | --- | --- |
| 曲目 ID `trackId` | string | 必显 | 用于播放 | 无 |
| 标题 `title` | string | 必显 | 优先使用最新编辑值 | 无 |
| 艺人 `artist` | string | 必显 | 无值时显示“未知艺人” | 无 |
| 最近播放时间 `playedAt` | datetime | 必显 | 展示最近一次点播时间 | 无 |

## 模块 D：交互与状态流转

### 操作 1：加载用户首页
- **触发事件**：访问 `/dashboard`。
- **前置校验**：用户已登录。
- **流转结果**：调用 `library.dashboard` 聚合查询。
- **成功结果**：渲染统计卡片、继续收听、最近播放、最近更新歌单与最近更新曲目。
- **失败结果**：展示页面级加载失败提示。

### 操作 2：从最近播放继续点播
- **触发事件**：点击最近播放行内按钮。
- **前置校验**：曲目仍存在且当前用户可见。
- **流转结果**：若当前 queue 不是首页最近播放队列，则先 `replaceQueueFromUserIntent`，再 `requestPlayTrack`。
- **成功结果**：全局播放器开始或继续播放。
- **失败结果**：展示播放失败提示。

### 操作 3：进入歌单或音乐库
- **触发事件**：点击最近更新歌单或“前往音乐库”。
- **前置校验**：目标路由可访问。
- **流转结果**：执行页面跳转。
- **成功结果**：进入对应页面。
- **失败结果**：显示导航失败提示。

### 页面状态与异常
- **加载中**：首页各区块显示 loading/空壳提示。
- **无数据**：最近播放、最近更新歌单、最近更新曲目都要有独立空状态。
- **网络错误**：显示错误提示，保留已渲染内容。
- **无权限**：未登录时跳转 `/sign-in`。
- **重复提交**：最近播放按钮在准备中显示 loading。
- **分页逻辑**：v1 不分页。
- **搜索逻辑**：首页不提供搜索。
- **排序逻辑**：最近播放按最近点播时间；最近更新歌单和最近更新曲目都按 `updatedAt desc`。
