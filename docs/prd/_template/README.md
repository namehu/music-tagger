# 模块 PRD 模板

本目录提供一个最小可用模板，文件矩阵与 frontmatter 约束对齐 `prd-structuring-agent` 的校验规则。

建议用法：

1. 复制整个目录到 `docs/prd/<module>/`
2. 替换 frontmatter 和正文占位内容
3. 补至少一个 `*-page.md`
4. 运行校验脚本

模板文件：

- `normalized-brief.md`
- `summary.md`
- `example-page.md`
- `gaps-and-assumptions.md`
- `quality-report.md`
- `implementation-handoff.md`
