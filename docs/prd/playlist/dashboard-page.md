# 用户首页

## 模块 A：页面元数据

- **页面名称**：用户首页
- **访问路由**：`/dashboard`
- **权限要求**：所有已登录用户可访问；管理员也默认从这里进入。

## 模块 B：UI/布局结构

- **页面布局模式**：轻量入口页，采用顶部说明 + 统计卡片 + 当前播放摘要 + 歌单入口列表。
- **核心区块划分**：
  - [统计卡片区]：展示曲目、专辑、艺人数量。
  - [当前播放区]：复用全局播放摘要组件。
  - [快速入口区]：跳转 `/library`、`/playlists`。
  - [最近歌单区]：列出最近更新的歌单。
- **页面内从属交互**：
  - 当前无弹窗类从属交互。

## 模块 C：数据展示与字段定义

### 字段分组 1：统计卡片字段
| 字段名称 (中/英) | 数据类型 | 必填/选填 | 业务规则/约束 | 默认值 |
| --- | --- | --- | --- | --- |
| 曲目数 `tracks` | integer | 必显 | 来自 `library.stats` | `0` |
| 专辑数 `albums` | integer | 必显 | 来自 `library.stats` | `0` |
| 艺人数 `artists` | integer | 必显 | 来自 `library.stats` | `0` |

### 字段分组 2：最近歌单字段
| 字段名称 (中/英) | 数据类型 | 必填/选填 | 业务规则/约束 | 默认值 |
| --- | --- | --- | --- | --- |
| 歌单 ID `id` | string | 必显 | 点击进入详情 | 无 |
| 歌单名称 `name` | string | 必显 | 展示用户自定义名称 | 无 |
| 曲目数 `itemCount` | integer | 必显 | 展示当前歌单项数量 | `0` |

## 模块 D：交互与状态流转

### 操作 1：进入用户首页
- **触发事件**：用户登录成功或访问 `/dashboard`。
- **前置校验**：用户已登录。
- **流转结果**：加载统计信息、歌单列表和当前播放摘要。
- **成功结果**：展示首页入口内容。
- **失败结果**：显示错误提示或框架级跳转登录。

### 操作 2：进入曲库或歌单页
- **触发事件**：点击快速入口卡片或最近歌单项。
- **前置校验**：目标路由可访问。
- **流转结果**：执行页面跳转。
- **成功结果**：进入对应页面。
- **失败结果**：展示导航失败提示。

### 页面状态与异常
- **加载中**：统计卡片和歌单列表显示 loading。
- **无数据**：没有歌单时显示空状态提示。
- **网络错误**：显示错误提示，保留已渲染区域。
- **无权限**：未登录时由框架跳转 `/sign-in`。
- **重复提交**：当前页面无提交型操作。
- **分页逻辑**：v1 不分页，仅展示最近若干歌单。
- **搜索逻辑**：当前页面不提供搜索。
- **排序逻辑**：最近歌单按更新时间倒序。

## 模块 E：复杂业务逻辑图

无复杂状态流转。
