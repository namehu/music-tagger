# 用户曲库页

## 模块 A：页面元数据

- **页面名称**：用户曲库页
- **访问路由**：`/library`
- **权限要求**：所有已登录用户可访问；不暴露管理员专属编辑操作。

## 模块 B：UI/布局结构

- **页面布局模式**：列表页，采用顶部说明 + 统计卡片 + 搜索/排序区 + 曲目表格。
- **核心区块划分**：
  - [统计卡片区]：展示曲目、专辑、艺人数量。
  - [搜索排序区]：关键字搜索与排序按钮。
  - [曲目表格区]：展示播放按钮、标题、艺人、专辑、路径、更新时间。
- **页面内从属交互**：
  - 当前无抽屉/弹窗；播放直接由全局播放器接管。

## 模块 C：数据展示与字段定义

### 字段分组 1：搜索与筛选字段
| 字段名称 (中/英) | 数据类型 | 必填/选填 | 业务规则/约束 | 默认值 |
| --- | --- | --- | --- | --- |
| 关键字 `q` | string | 选填 | 匹配标题、艺人、专辑、文件名、路径 | 空 |
| 排序 `order` | enum | 必填 | `recent / title / artist` | `recent` |

### 字段分组 2：曲目表格列
| 字段名称 (中/英) | 数据类型 | 必填/选填 | 业务规则/约束 | 默认值 |
| --- | --- | --- | --- | --- |
| 播放按钮 `play` | action | 必显 | 进入全局播放器 | 无 |
| 标题 `title` | string | 必显 | 优先显示 override 后标题 | 无 |
| 艺人 `artist` | string | 选显 | 无值时显示占位 | 空 |
| 专辑 `album` | string | 选显 | 无值时显示占位 | 空 |
| 路径 `path` | string | 必显 | 只读展示 | 无 |
| 更新时间 `updatedAt` | datetime | 必显 | 表格展示 | 无 |

## 模块 D：交互与状态流转

### 操作 1：搜索和排序曲库
- **触发事件**：输入关键字或点击排序按钮。
- **前置校验**：用户已登录。
- **流转结果**：调用 `tracks.list` 重新拉取结果。
- **成功结果**：刷新表格结果。
- **失败结果**：显示加载失败提示。

### 操作 2：点播曲目
- **触发事件**：点击曲目播放按钮。
- **前置校验**：曲目存在，用户已登录。
- **流转结果**：触发 `playback.resolve`，必要时轮询转码准备状态。
- **成功结果**：当前曲目进入全局播放器。
- **失败结果**：展示播放或转码失败提示。

### 页面状态与异常
- **加载中**：统计卡片与表格显示 loading。
- **无数据**：无曲目时提示先执行 `scan_full`。
- **网络错误**：显示错误提示，允许重试。
- **无权限**：未登录时跳转 `/sign-in`。
- **重复提交**：播放按钮在准备中展示 loading，避免重复点击。
- **分页逻辑**：v1 仅做固定数量结果，不做完整分页。
- **搜索逻辑**：优先走 FTS，失败时降级 LIKE。
- **排序逻辑**：支持 `recent / title / artist`。
