# 歌单列表页

## 模块 A：页面元数据

- **页面名称**：歌单列表页
- **访问路由**：`/playlists`
- **权限要求**：所有已登录用户可访问，只可操作自己的歌单。

## 模块 B：UI/布局结构

- **页面布局模式**：表单 + 卡片列表页。
- **核心区块划分**：
  - [新建区]：输入歌单名称并创建。
  - [歌单卡片区]：展示已有歌单及其管理操作。
- **页面内从属交互**：
  - 当前无弹窗，重命名在卡片内联完成。

## 模块 C：数据展示与字段定义

### 字段分组 1：新建歌单字段
| 字段名称 (中/英) | 数据类型 | 必填/选填 | 业务规则/约束 | 默认值 |
| --- | --- | --- | --- | --- |
| 歌单名称 `name` | string | 必填 | 去首尾空格，长度 1..120 | 空 |

### 字段分组 2：歌单卡片字段
| 字段名称 (中/英) | 数据类型 | 必填/选填 | 业务规则/约束 | 默认值 |
| --- | --- | --- | --- | --- |
| 歌单 ID `id` | string | 必显 | 用于跳转详情页 | 无 |
| 歌单名称 `name` | string | 必显 | 支持重命名 | 无 |
| 曲目数 `itemCount` | integer | 必显 | 当前歌单项数量 | `0` |
| 创建时间 `createdAt` | datetime | 必显 | 只读展示 | 无 |
| 最近更新时间 `updatedAt` | datetime | 必显 | 列表默认倒序 | 无 |

## 模块 D：交互与状态流转

### 操作 1：创建歌单
- **触发事件**：输入名称并点击“创建歌单”。
- **前置校验**：名称不能为空。
- **流转结果**：调用 `playlists.create`。
- **成功结果**：创建成功并刷新列表。
- **失败结果**：保留输入并展示错误提示。

### 操作 2：重命名歌单
- **触发事件**：点击“重命名”，修改名称后保存。
- **前置校验**：当前用户拥有该歌单；名称不能为空。
- **流转结果**：调用 `playlists.rename`。
- **成功结果**：更新名称并关闭编辑态。
- **失败结果**：保留编辑态并展示错误提示。

### 操作 3：删除歌单或进入详情
- **触发事件**：点击“删除”或“打开歌单”。
- **前置校验**：当前用户拥有该歌单。
- **流转结果**：删除时调用 `playlists.remove`；进入详情时执行跳转。
- **成功结果**：删除后刷新列表，跳转后进入详情页。
- **失败结果**：展示错误提示。

### 页面状态与异常
- **加载中**：歌单列表显示 loading。
- **无数据**：显示空状态提示新建歌单。
- **网络错误**：显示错误提示。
- **无权限**：未登录时跳转 `/sign-in`。
- **重复提交**：创建/重命名/删除按钮进入 loading。
- **分页逻辑**：v1 不分页。
- **搜索逻辑**：v1 不提供搜索。
- **排序逻辑**：按 `updatedAt DESC`。

无复杂状态流转。
