# Archive

本目录只存放历史输入材料与已退出标准治理流程的旧文档。

使用规则：

- `docs/archive/raw-requirements/`：原始需求稿、会议纪要、草案白皮书等历史输入
- 归档文档可以作为 PRD 的背景来源，但不能作为当前系统事实源
- 当前事实以 `docs/architecture.md` 与 `docs/baseline/*` 为准
- 未来目标以 `docs/prd/*` 为准
- 工程实施以 `docs/implementation-plans/*` 为准

这意味着：

- 归档目录用于保留决策上下文
- 不应把归档材料直接当成“当前实现已经如此”的依据
